# 8장. 주간 경쟁, 마이페이지, 타이머

## 주간 경쟁: `src/pages/weeklyRank/`

### `weeklyRankApi.js`

API 하나(`GET /main/week_competition`)로 화면 전체 데이터를 받아요. 명세서에 안쪽 필드 이름이 없어서 여러 이름을 받게 해 뒀어요.

**`toRanker(raw, me)`**: 순위 한 줄을 화면용 모양 `{ rank, name, title, minutes, image, me }`로 바꿔요. `title`은 이름 앞에 붙는 **업적**이에요.

**`isbnOf(raw)`**: ISBN을 꺼내요. 글자로 오든 객체로 오든 받아요.

**`findBookByIsbn(isbn)`**: ISBN으로 YES24를 검색해 첫 번째 책을 돌려줘요.

**`withCover(raw)`**: 표지를 채워요. 백엔드가 표지를 주면 그대로, 없으면 YES24에서 찾아요.

**`loadCompetitorBooks(list)`**: 경쟁자 책을 최대 5권 불러와요.
```js
const books = await Promise.all(items.map(withCover));
```
`Promise.all`은 **여러 요청을 동시에 보내고 전부 끝나길** 기다려요. 하나씩 기다리는 것보다 빨라요.

**`loadReadingBook(raw)`**: 오른쪽 카드의 책이에요. 진행률을 계산하고, 타이머에 넘길 `serverBookId`도 넣어요.

**`toLastWeek(raw)`**: 지난주 결과. 등수가 없으면 `null`이에요.

**`MOCK_COMPETITION`**: 백엔드가 없을 때 보여 주는 임시값이에요. **백엔드 연결 후 삭제해요.**

**`requestCompetition()`**: 서버에 요청하고 실패하면 임시값을 돌려줘요.

**`fetchWeekCompetition()`**: 위 함수들을 모아 화면용 데이터를 만들어요.

**`currentWeekKey()`**: 이번 주 월요일 날짜예요. 알림을 한 주에 한 번만 띄우는 데 써요.

**`formatMinutes(minutes)`**: `637` → `10시간 37분`

### `WeeklyRank.jsx`

**`TIER_IMAGES`**: 티어 이름과 이미지를 연결해요.
```jsx
{TIER_IMAGES[data?.tier] ? <img .../> : data && <div>{data.tier}</div>}
```
모르는 티어가 오면 이름을 글자로 보여 줘요.

**`showLastWeekResult(lastWeek)`**: 이번 주에 이미 봤으면 그냥 돌아가고, 아니면 저장하고 XP 알림을 띄워요.

**`RankRow`**: 순위 한 줄이에요. 사진이 없으면 `Avatar`를 그려요.

**`ReadingBook`**: 오른쪽 카드예요. 책이 없으면 "읽고 있는 책이 없어요."를 보여 줘요.

**`WeeklyRank`**:
```jsx
const myImage = useMyImage("profile");
<RankRow ranker={{ ...data.me, image: myImage || data.me.image }} />
```
내 줄에는 마이페이지에서 바꾼 사진을 넣어요.

## 마이페이지: `src/pages/myPage/`

### `myPageApi.js`

| 함수 | API |
|---|---|
| `fetchMyPage()` | `GET /users/my_page` |
| `fetchEditPage()` | `GET /users/edit_page` |
| `saveEditInfo({...})` | `PUT /users/edit_info` |
| `applyTitle(titleID)` | `PUT /users/title` (이름 앞 업적 고르기) |
| `uploadImage(kind, file)` | `PUT /users/image` |
| `resetImage(kind)` | 이미지 삭제 (명세서에 없어서 임시 방식) |

**`load(url, mock)`**: 요청하고 실패하면 임시값을 써요. `MOCK_MY_PAGE`, `MOCK_EDIT_PAGE`가 임시값이고 **연결 후 삭제**해요.

**`toAchievement(raw)`**: 업적 한 줄을 화면용으로 바꿔요.

**`sortAchievements(list)`**: 달성한 것과 못 한 것으로 나누고, 사용 중인 업적을 맨 앞에 둬요.
```js
.sort((a, b) => Number(b.used) - Number(a.used))
```
`true`는 1, `false`는 0이라 사용 중인 게 앞으로 와요.

**`uploadImage`** 는 파일을 보내려고 `FormData`를 써요. 이때는 `Content-Type`을 직접 넣지 않아요. 브라우저가 알아서 넣어요.

**`formatHours(minutes)`**: `9120` → `152시간`

### `parts.jsx`

- **`ICONS`, `Icon`**: 아이콘 모음. `<Icon name="clock" size={50} />`처럼 써요. `stroke="currentColor"`라 글자색을 따라가요.
- **`ImagePencil`**: 초록 연필 버튼이에요.
  - 사진이 없으면 누르자마자 파일 선택 창이 열려요.
  - 사진이 있으면(`canReset`) 메뉴(사진 바꾸기 / 삭제하기)가 열려요.
  - `<input type="file" hidden>`을 숨겨 두고 `inputRef.current.click()`으로 대신 눌러요.
  - `e.target.value = ""`로 비워야 같은 파일을 다시 골라도 동작해요.
- **`Banner`**: 배경 이미지. 사진이 있으면 `has-image` 클래스로 꽉 채워요. 없으면 CSS로 그린 밤하늘이에요.
- **`ProfileImage`**: 프로필 사진. 없으면 `Avatar`예요.

### `useProfileImages.js`

마이페이지와 회원정보 수정이 같이 쓰는 훅이에요.

- `images`: 지금 사진 (`useMyImage`에서 읽어요)
- **`setImages(images)`**: 서버가 준 주소를 저장해요. **빈 값은 건너뛰어요.** 임시값이 사용자가 고른 사진을 지우면 안 되니까요.
- **`changeImage(kind, file)`**: 줄인 사진을 먼저 저장해 바로 보여 주고, 서버에 올려요. 서버 주소를 받으면 그걸로 바꿔요.
- **`resetToDefault(kind)`**: 사진을 지워요.

### `MyPage.jsx`

- **`StatCard`**: 통계 카드 (1장에서 봤어요).
- **`Achievement`**: 업적 한 줄이에요. 달성했고 사용 중이 아니면 **눌러서 쓸 수 있게 `button`으로**, 아니면 `div`로 그려요.
- **`chooseTitle(item)`**: 서버에 보내고 성공하면 화면을 고쳐요. 사용 표시를 옮기고 다시 정렬해요.

```jsx
{data.achieved.length > 0 && data.locked.length > 0 && <hr />}
```
두 묶음이 다 있을 때만 구분선을 그려요.

### `EditInfo.jsx`

- **`Field`**: 라벨과 입력칸 묶음이에요. `<label>`로 감싸서 라벨을 눌러도 입력칸에 들어가요.
- **`PasswordField`**: 눈 모양으로 보이기/숨기기를 하는 비밀번호 칸이에요. `type={visible ? "text" : "password"}`.

**`update(key, value)`**: `form`의 값 하나를 바꿔요.
```js
setForm((prev) => ({ ...prev, [key]: value }));
```
`[key]`는 변수 값을 속성 이름으로 쓰는 문법이에요.

**`passwordStatus`**: 비밀번호 검사 결과예요. **state가 아니라 그릴 때마다 계산**해요. 그래서 입력하는 동안 문구가 바로 바뀌어요.

**`shownStatus(key)`**: 아직 안 친 칸은 저장을 누르기 전까지 문구를 안 보여 줘요. 처음부터 빨간 글씨가 뜨면 안 좋으니까요.

**`save()`**: 이름 → 목표 시간 → 비밀번호 순으로 검사하고, 통과하면 서버에 보내요. 성공하면 0.8초 뒤 마이페이지로 돌아가요.

이메일 칸은 `readOnly`라 수정할 수 없어요.

### `Timer.jsx`

**도우미 함수**

- **`useScreenScale()`**: 사이드바가 없어서 `useFitScale` 대신 전용으로 만들었어요.
- **`toSeconds("00:30")`** → `1800`
- **`pad(5)`** → `"05"`
- **`formatClock(754)`** → `"00 : 12 : 34"`
- **`formatRemain(1073)`** → `"17분 53초"`

**`useStopwatch(running)`**: 읽은 시간을 세는 훅이에요.
```js
const useStopwatch = (running) => {
  const [elapsed, setElapsed] = useState(0);
  const base = useRef(0);                         // 지금까지 쌓인 초
  useEffect(() => {
    if (!running) return undefined;
    const startedAt = Date.now();                 // 시작 시각
    const passed = () => Math.floor((Date.now() - startedAt) / 1000);
    const id = setInterval(() => setElapsed(base.current + passed()), 250);
    return () => {                                // 멈출 때
      clearInterval(id);
      base.current += passed();                   // 지금까지를 쌓아 둔다
      setElapsed(base.current);
    };
  }, [running]);
  return elapsed;
};
```
**"1초마다 1 더하기"로 안 만든 이유**: 탭이 백그라운드로 가면 브라우저가 `setInterval`을 느리게 돌려요. 그러면 시간이 틀려져요. 그래서 **실제 시각의 차이**로 계산해요.

**`Timer`의 state**

`step`이 화면을 정해요.
```
setup(목표 입력) → reading(읽는 중) → askClose(여기까지?) → pages(쪽수 입력) → 감상문으로 이동
                       ↑__________ 아니요 ___|
```

| state | 의미 |
|---|---|
| `goal` | 목표 시간 `"00:30"` |
| `running` | 시간이 가는 중인지 |
| `clockHidden` | 시계를 숨겼는지 |
| `adding` | 시간 추가 입력 중인 값. `null`이면 입력 안 함 |
| `page` | 입력한 쪽수 |
| `quoteOpen` | 인용구 팝업이 열렸는지 |

```js
const goalSeconds = toSeconds(goal);
const reached = elapsed >= goalSeconds;   // 목표 달성 여부. state 가 아니라 계산값
```

| 함수 | 하는 일 |
|---|---|
| `start()` | 목표 확인 후 시작 |
| `addTime()` | 목표에 시간 더하기 (최대 23:59) |
| `closeBook()` | 멈추고 물어보기 |
| `keepReading()` | '아니요'를 누르면 다시 시작 |
| `finish()` | 쪽수 검사 → 저장 → 감상문으로 |
| `saveQuote()` | 인용구 저장 |

**`finish()`**:
```js
const [, pageResult] = await Promise.all([addStudyTime(serverId, minutes), saveReadPages(serverId, readPage)]);
```
두 요청을 동시에 보내요. `[, pageResult]`는 첫 번째 결과는 버리고 두 번째만 쓴다는 뜻이에요.

```js
navigate(`${PATHS.review}?write=1`, { state: { book } });
if (xp > 0) setTimeout(() => showXpToast({ title: "독서 보상", xp }), 300);
```
XP 알림은 `Layout`에 붙어 있는데 타이머는 `Layout` 바깥이에요. 그래서 감상문 화면(레이아웃 안)으로 간 뒤 0.3초 후에 띄워요.

**`renderBubble()`**: `step`에 따라 말풍선 안에 그릴 내용을 골라요. `if`로 먼저 `return`하는 방식이에요.

```jsx
<section className={`tm-bubble ${step === "reading" && clockHidden ? "short" : ""}`}>
```
시계를 숨기면 말풍선이 낮아져요.
