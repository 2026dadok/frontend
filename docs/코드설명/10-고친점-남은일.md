## 남은 일

### 출시 전에 꼭 해야 할 것

1. **로그인 확인 켜기.** 지금은 로그인 안 해도 모든 화면이 열려요. `App.jsx`의 `RequireAuth`로 감싸면 돼요.
2. **로그아웃 만들기.** 로그아웃 버튼이 어디에도 없어요. `POST /auth/logout` API는 있어요.
3. **설정 화면 만들기.** `/settings`가 "설정" 글자뿐이에요. 로그아웃이 여기 들어가면 좋겠어요.
4. **회원탈퇴 만들기.** 약관에 "마이페이지에서 탈퇴할 수 있다"고 썼는데 버튼이 없어요. `DELETE /users/me` API는 있어요.
5. **임시값 지우기.** `MOCK_COMPETITION`, `MOCK_MY_PAGE`, `MOCK_EDIT_PAGE`가 남아 있으면, 서버 오류 때 **가짜 사용자 정보**가 보여요. `TODO: 백엔드 연결 후 삭제`로 검색하세요.
6. **토큰 만료 처리.** 로그인이 만료됐을 때(401 응답) 처리가 없어요. `refreshToken`을 저장만 하고 쓰지 않아요.
7. **약관 검토.** 초안이에요. 시행일, 문의처, 만 14세 미만 동의 절차를 확인하세요. (`legalDocs.js` 맨 위)

### 백엔드에 물어볼 것

- `POST /library/books`: 명세서는 `bookID`인데, 처음 담는 책은 서버 번호가 없어요. 무엇을 보내야 하나요?
- `/auth/rest-passwrod`: 오타인가요? 실제 주소는요?
- `/auth/pw_reset`의 `token`은 어디서 받나요?
- `GET /quests/weekly`, `/quests/daily`: 명세서에 없는데 홈에서 씁니다.
- 총 XP를 받을 API가 없어요.
- 마이페이지·주간 경쟁 응답의 안쪽 필드 이름, 읽은 시간 단위(지금은 분으로 가정)
- 이미지 삭제 방법, 프로필/배경 구분 방법, 현재 비밀번호 확인 방법
- 함께 읽기 수락 여부를 어떻게 아나요? 지금은 요청만 보내고, 공동 서재에 책이 추가되는 코드가 연결돼 있지 않아요.
