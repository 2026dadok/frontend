# 6장. 홈과 책 검색

## 홈: `src/pages/home/`

### `homeApi.js`: 홈의 데이터

| 함수 | 하는 일 | 데이터 출처 |
|---|---|---|
| `fetchRecommendedBooks()` | 이달의 추천 도서 6권 | YES24 베스트셀러 |
| `fetchMyLibraryBooks()`, `fetchSharedLibraryBooks()` | 서재 목록 | localStorage |
| `fetchWeeklyQuest()`, `fetchDailyQuests()` | 퀘스트 | 백엔드 (명세서에 없음) |
| `loadDailyQuests()` | 출석을 먼저 보내고 일일 퀘스트 받기 | 백엔드 |
| `fetchTotalXp()` | 총 XP. **지금은 항상 0** | 없음 (API 필요) |
| `fetchRandomQuote()` | 인용구 하나 무작위로 | localStorage |

`getJson(url, options)`: `fetch`하고 실패하면 오류를 던져요. `useLoad`의 `.catch`가 받아요.

`loadDailyQuests`에서 출석을 **먼저** 보내는 이유는, 그래야 받아 온 목록에 출석 완료가 반영되기 때문이에요.

### `Home.jsx`

**`useLoad(loader, initial)`**: 이 파일 전용 훅이에요.
```js
const useLoad = (loader, initial) => {
  const [data, setData] = useState(initial);       // 처음에는 임시값
  useEffect(() => {
    let alive = true;
    Promise.resolve()
      .then(loader)                                // loader 실행
      .then((v) => alive && v != null && setData(v))
      .catch((e) => console.error(e));             // 실패하면 임시값 유지
    return () => { alive = false; };
  }, [loader]);
  return data;
};
```
`FALLBACK_WEEKLY`, `FALLBACK_DAILY`가 임시값이에요. 서버가 없어도 화면이 나와요.

**`Shelf`**: 서재 카드예요. `books.slice(0, 4)`로 최대 4권만 보여 주고 맨 끝에 `+` 칸을 둬요.

**`Recommend`**: 추천 도서예요. 누르면 `onOpen(b)`로 책 상세를 열어요.

**`Xp`**: 작은 `XP 10` 표시예요.

**`WeeklyQuest`**: 진행 막대의 너비를 계산해요.
```js
const percent = Math.min(100, (quest.current / quest.goal) * 100) || 0;
```
`|| 0`은 goal이 0이라 `NaN`이 될 때를 막아요.

**`DailyQuest`**: 일일 퀘스트 목록과 전체 완료 보상이에요. 완료 여부는 **백엔드가 준 `done`만** 써요.

**`QuoteBubble`**: 오늘의 문장 말풍선이에요. 기본 내용과 호버 내용을 CSS Grid로 같은 칸에 겹쳐 놓고, 마우스를 올리면 투명도로 바꿔요.

**`Home`**: 위의 조각을 모아요.
```js
const [quote] = useState(fetchRandomQuote);   // 처음 한 번만 뽑는다
const openRecommended = (book) => navigate(PATHS.search, { state: { book } });
```
추천 도서를 누르면 책 검색 화면으로 가면서 `state`로 책을 넘겨요. 받는 쪽은 바로 상세 화면을 열어요.

## 책 검색: `src/pages/bookSearch/`

### `bookSearchApi.js`: YES24 호출

브라우저는 `/yes24/v1/...`로 요청하고, Vite 프록시가 키를 붙여 YES24로 전달해요.

**`cleanText(text)`**: 책 소개에 섞인 HTML 태그(`<br>`, `&nbsp;` 등)를 걷어 내요.

**`parseAuthors(author)`**: `"무라카미 하루키 저/홍은주 역"` 같은 글자를 저자와 번역가로 나눠요.
1. `/`로 역할별 묶음을 나눠요.
2. 묶음을 `,`로 나누고, 끝의 역할 단어(`저`, `역`…)를 봐요.
3. 이름에서 역할 단어를 떼고 저자 또는 번역가 목록에 넣어요.

**`formatCreators(names)`**: 저자가 많으면 `김난도 외 4명`처럼 줄여요.

**`toRawCategory(sortName)`**: `"국내도서-소설/시/희곡"` → `"소설/시/희곡"`

**`toBook(item)`**: **YES24 응답을 우리 화면에서 쓰는 모양으로 바꾸는** 함수예요. 화면은 이 함수가 만든 모양(`id`, `title`, `cover`, `intro`, `pages` 등)만 알면 돼요. YES24가 바뀌어도 여기만 고치면 돼요.

**`getJson(url)`**: 404(결과 없음)는 오류가 아니라 빈 결과로 봐요.

**`toPage(json, page)`**: 응답을 `{ books, total, hasMore }`로 바꿔요. `adultYn`이 `Y`인 성인 도서는 빼요.

| 함수 | 하는 일 |
|---|---|
| `fetchBestsellers(page, categoryId)` | 월별 베스트셀러 |
| `searchBooks(query, page)` | 제목·저자 검색 |
| `fetchGenreBooks(genre, page)` | 장르별 인기 책 |
| `fetchAuthorOtherBooks(book)` | 이 작가의 다른 작품 |
| `fetchBookIntro(book)` | 소개가 없는 책의 소개 다시 찾기 |

`fetchAuthorOtherBooks`는 YES24에 저자별 API가 없어서, 저자 이름으로 검색한 뒤 **같은 저자만, 세트 제외, 같은 책의 다른 판본 제외**로 걸러요.

### `genres.js`: 장르

**`classifyGenre({ rawCategory, title, intro })`**: YES24에는 큰 분류만 있어서, 소설은 제목과 소개에 나오는 단어로 장르를 추측해요. `NOVEL_KEYWORDS`의 단어가 2개 이상 나오거나 제목에 나오면 그 장르로 봐요.

**`GENRE_OPTIONS`**: 장르 선택 목록이에요. `categoryId`가 있으면 YES24 카테고리 베스트셀러를, `query`가 있으면 검색 결과에서 소설만 보여 줘요.

### `useInfiniteBooks.js`: 무한 스크롤 훅

```js
const useInfiniteBooks = (loadPage) => { ... return { ...state, loadMore }; };
```
`loadPage(page)`를 받아 결과를 계속 쌓아요.

- `pageRef`: 지금까지 불러온 쪽수. 화면과 상관없어서 ref예요.
- `busyRef`: 불러오는 중이면 또 부르지 않게 막아요.
- `generationRef`: **늦게 온 응답을 버리는 번호표**예요. 검색어를 바꿨는데 이전 검색 결과가 늦게 도착하면 섞이니까, 번호가 다르면 무시해요.
- `seen`: 이미 있는 책은 또 넣지 않아요. 페이지가 겹쳐도 `key`가 중복되지 않게요.

두 번째 `useEffect`: `loadPage`가 바뀌면(검색어 변경) 전부 비우고 처음부터 불러와요.

### `parts.jsx`: 작은 부품들

책 검색과 다른 화면들이 같이 써요.

| 컴포넌트 | 하는 일 |
|---|---|
| `SearchBar` | 검색창. 한글 조합 중 Enter로 검색되는 걸 막아요 (`isComposing`) |
| `ScrollArea` | 끝까지 스크롤하면 `onLoadMore`를 불러요 |
| `ListStatus` | 불러오는 중 / 오류 / 빈 목록 문구 |
| `Stars` | 별점 표시 |
| `StarInput` | 별점 입력 |
| `Avatar` | 회색 기본 프로필 그림 (SVG) |
| `Toast` | 알림 문구 |
| `XpTotal` | 오른쪽 위 총 XP |

**`ScrollArea`** 는 `IntersectionObserver`를 써요. 맨 아래에 보이지 않는 `<div ref={endRef}>`를 두고, 그게 화면에 들어오면 더 불러와요. `rootMargin: "0 0 300px 0"`은 300px 전에 미리 불러오라는 뜻이에요.

### `BookSearch.jsx`: 화면 전체 관리

한 주소(`/search`) 안에서 `view` state로 화면을 바꿔요.

```
list(베스트셀러) → results(검색 결과) / detail(책 상세) → invite(친구 초대) → shared(공동서재)
```

**맨 아래의 `BookSearch`**:
```jsx
<BookSearchFlow key={location.key} initialBook={location.state?.book ?? null} ... />
```
`key`가 바뀌면 리액트는 컴포넌트를 **처음부터 새로 만들어요.** 사이드바에서 '책 검색'을 다시 누르면 첫 화면으로 돌아가게 하는 요령이에요.

**`BookSearchFlow`의 state**: `view`(현재 화면), `query`(검색창 글자), `term`(실제 검색한 단어), `book`(선택한 책), `genre`(고른 장르).

`query`와 `term`이 나뉜 이유는, 글자를 칠 때마다 검색하면 안 되고 Enter를 눌렀을 때만 검색해야 해서예요.

```js
const genreLoader = useCallback((page) => fetchGenreBooks(genre, page), [genre]);
const bestsellers = useInfiniteBooks(genreLoader);
```
`genre`가 바뀌면 `genreLoader`가 새 함수가 되고, 훅이 처음부터 다시 불러와요.

| 함수 | 하는 일 |
|---|---|
| `handleSearch()` | 검색어 확인 후 결과 화면으로 |
| `openBook(b)` | 책 상세 열기 |
| `addMine(b)` | 나의 서재에 담고 결과를 알림으로 |
| `openInvite(b)` | 친구 초대 화면 열기 |
| `startTogether({ id, name })` | 함께 읽기 요청 보내기 |
| `readNow(b)` | 타이머로 이동 |

**`readNow`** 는 서재에 담아 둔 책이면 서버 번호까지 같이 넘겨요.
```js
const shelf = getMyLibrary().find((item) => item.id === b.id);
navigate(PATHS.timer, { state: { book: { ...b, totalPage: b.pages, ...shelf } } });
```

### `SearchResults.jsx`

검색 결과 카드예요. 카드 전체를 눌러도 상세로 가고, 안의 버튼도 따로 동작해요.
```js
const stop = (handler) => (e) => {
  e.stopPropagation();   // 버튼 클릭이 카드 클릭으로 번지지 않게

```

### `BookDetail.jsx`: 책 상세

왼쪽은 표지와 버튼, 오른쪽은 스크롤되는 내용이에요.

state: `reviews`, `rating`, `content`, `expanded`(소개 펼침), `editing`(리뷰 수정 중), `others`(다른 작품, `null`이면 불러오는 중).

```js
const mine = reviews.find((r) => r.userKey === me.key);   // 내 리뷰
const { average } = summarizeReviews(reviews);            // 평균 별점
const intro = book.intro ?? "";                           // 소개가 없는 책도 있다
```

**`submitReview()`** 는 버튼 하나로 세 가지 일을 해요.
- 이미 쓴 리뷰가 있고 수정 중이 아니면 → 수정 모드로
- 수정 중이면 → `updateMyReview()`로 서버에 저장
- 처음이면 → `saveMyReview()`로 등록

### `SharedLibrary.jsx`

공동서재 화면의 내용이에요. 책 검색과 공동서재 페이지가 같이 써요.

**`Progress`**: 프로필과 진행 막대예요.
**`SharedLibrary`**: `useMyImage("profile")`로 내 사진을 가져와요. 사진을 바꾸면 여기도 자동으로 바뀌어요.

### `bookStore.js`: 서재 저장소

**중요한 파일이에요.** 서재, 공동 서재, 감상문, 리뷰를 다뤄요. 백엔드를 연결하면 이 파일 안쪽을 API 호출로 바꾸게 돼요.

**`read(key, fallback)`, `write(key, value)`**: localStorage를 안전하게 읽고 써요. 저장 실패 시 오류 대신 `false`를 돌려줘요.

**`getMe()`**: 내 정보를 돌려줘요. `key`는 구분용 아이디, `displayName`은 화면에 보여 줄 이름이에요. 로그인 안 했으면 `"나"`예요.

**`toShelfBook(book)`**: 서재에 저장할 모양으로 바꿔요. `pages`를 `totalPage`로, `addedAt`에 담은 시각을 넣어요.

| 함수 | 하는 일 |
|---|---|
| `getMyLibrary()` | 나의 서재 읽기 |
| `addToMyLibrary(book)` | 서버에 등록 시도 후 브라우저에 저장. `"added"`, `"exists"`, `"error"` 중 하나를 돌려줘요 |
| `updateShelfBook(id, patch)` | 서재의 책 정보 일부 고치기 |
| `removeFromMyLibrary(id)` | **서버가 성공해야만** 삭제 |
| `markAdded(id)`, `getAddedCount(id)` | 이 책을 담은 사람 수 |
| `getSharedLibrary()` | 공동 서재 읽기 |
| `requestCoReading(id, name)` | 함께 읽기 요청 |
| `addToSharedLibrary(book, friend)` | 공동 서재에 추가 (아직 부르는 곳 없음) |
| `getCommentaries(id)`, `addCommentary(book, day, content)` | 감상문 |
| `daysSince(iso)` | 시작일로부터 며칠 지났는지 |
| `getReviews(id)`, `saveMyReview`, `updateMyReview`, `summarizeReviews` | 리뷰 |

`serverBookId`는 서버가 준 책 번호예요. 책의 `id`는 YES24 번호라서 둘은 달라요. 서버 API에는 `serverBookId`를 보내요.

**`daysSince`** 는 시각을 빼고 **날짜만** 비교해요. 어제 밤 11시와 오늘 새벽 1시는 2시간 차이지만 하루 차이로 쳐요.
