# 5장. 첫 화면과 약관

## 첫 화면: `src/pages/landing/Landing.jsx`

로그인 전 소개 페이지예요. **서버에서 받는 데이터가 없고** 내용이 전부 코드에 적혀 있어요.

### 내용을 배열로 빼 두기

```js
const FEATURES = [
  { no: "01", title: "나의 서재", image: myLibraryImg, width: 660, text: ["...", "..."] },
  ...
];
```
같은 모양이 반복되는 내용은 **데이터 배열로 만들고 `map`으로 그려요.** 문구를 고칠 때 이 배열만 보면 돼요. `GUIDES`(이용 가이드)와 `NAV`(메뉴)도 같아요.

### 컴포넌트와 함수

**`Shot`**: 화면 캡처 이미지예요. `style={{ width }}`로 보이는 크기를 정해요. 그래서 2배 크기 파일을 같은 이름으로 넣어도 크기는 그대로고 더 선명해져요.

**`GuideIcon`**: 이름에 맞는 아이콘을 SVG로 그려요. `{name === "person" && (...)}`로 하나만 골라요.

**`scrollToSection(id)`**: 그 `id`를 가진 영역으로 부드럽게 스크롤해요.
```js
document.getElementById(id)?.scrollIntoView({ behavior: "smooth" });
```

**`HeroLogo`**: 움직이는 로고예요.
```jsx
<h1 className="ld-logo" aria-label="다독다독">
  <span className="ld-logo-glyph" aria-hidden="true">
    <img className="da" src={glyphDaImg} alt="" />      {/* 왼쪽에서 들어옴 */}
    <img className="dok" src={glyphDokImg} alt="" />    {/* 오른쪽에서 들어옴 */}
    <img className="merged" src={glyphImg} alt="" />    {/* 마지막에 나타남 */}
  </span>
  <span className="ld-logo-rest" aria-hidden="true">
    <img className="da" src={daImg} alt="" />           {/* 움직이지 않음 */}
    <img className="dok" src={dokImg} alt="" />
  </span>
</h1>
```
앞 글자는 '다'와 '독'을 겹친 모양이에요. 세 이미지가 같은 자리, 같은 크기예요. 두 글자가 겹친 뒤 합친 글자가 위에서 서서히 나타나면, 안쪽 선만 사라지는 것처럼 보여요. `aria-label`과 `aria-hidden`은 화면 읽기 프로그램을 위한 거예요. 이미지 네 장 대신 "다독다독" 하나로 읽어 줘요.

**`Landing`**: 머리말, 첫 화면, 소개, 기능, 가이드, 푸터를 차례로 그려요.
```jsx
<article className={`ld-feature ${i % 2 ? "reverse tinted" : ""} ${f.image ? "" : "text-only"}`}>
```
짝수 번째 기능(`i % 2`가 1)은 이미지와 글을 좌우로 바꾸고 배경색을 넣어요. 이미지가 없으면 글만 나오게 해요.

### 애니메이션 (`Landing.css`)

```css
.ld-logo-glyph .da { animation: ld-from-left 1.1s cubic-bezier(0.22, 1, 0.36, 1) both; }
.ld-logo-glyph .merged { animation: ld-fade-in 0.35s ease-out 0.95s both; }

@keyframes ld-from-left {
  from { opacity: 0; transform: translateX(-50vw); }
  to   { opacity: 1; transform: none; }
}
```
- `@keyframes`: 시작과 끝 모습을 정해요.
- `1.1s`: 걸리는 시간, `0.95s`: 기다렸다 시작하는 시간이에요.
- `both`: 시작 전에는 첫 모습, 끝난 뒤에는 끝 모습을 유지해요.
- `cubic-bezier(...)`: 빠르게 시작해서 천천히 멈추는 속도 곡선이에요.
- `50vw`: 화면 너비의 절반이에요.
- `@media (prefers-reduced-motion: reduce)`: 움직임을 줄이는 설정을 켠 사용자에게는 애니메이션을 끄고 바로 보여 줘요.

`position: sticky`를 쓴 머리말은 스크롤해도 위에 붙어 있어요. `overflow-x: hidden`을 쓰면 sticky가 안 돼서 `overflow-x: clip`을 썼어요. `scroll-margin-top`은 스크롤로 이동할 때 머리말에 제목이 가리지 않게 해요.

## 푸터: `src/pages/landing/SiteFooter.jsx`

첫 화면과 약관 페이지가 같이 쓰는 푸터예요.
```js
const goSection = (id) => (onSection ? onSection(id) : navigate(PATHS.guest));
```
첫 화면에서는 `onSection`을 받아 스크롤하고, 약관 페이지에서는 받지 않으니 첫 화면으로 이동해요.

## 약관

### `src/pages/legal/legalDocs.js`

문서 내용이 데이터로 들어 있어요.
```js
export const TERMS = {
  title: "이용약관",
  sections: [
    { heading: "제1조 (목적)", body: ["..."] },   // body: 문단들
    { heading: "제2조 ...", list: ["...", "..."] }, // list: 점 목록
  ],
};
```
`PRIVACY`도 같은 모양이에요. **제가 쓴 초안이라 출시 전에 검토가 필요해요.** 파일 맨 위 `TODO`에 확인할 것이 적혀 있어요.

### `src/pages/legal/LegalPage.jsx`

`doc` props로 어떤 문서든 같은 모양으로 그려요. `App.jsx`에서 `<LegalPage doc={TERMS} />`처럼 넘겨요.

```jsx
useEffect(() => {
  window.scrollTo(0, 0);                         // 맨 위로
  const prevTitle = document.title;
  document.title = `${doc.title} | 다독다독`;      // 브라우저 탭 제목 바꾸기
  return () => {
    document.title = prevTitle;                  // 떠날 때 되돌리기
  };
}, [doc]);
```

```jsx
{section.body?.map((text) => <p key={text}>{text}</p>)}
{section.list && <ul>...</ul>}
```
항목마다 `body`나 `list`가 있을 수도 없을 수도 있어서 `?.`와 `&&`를 써요.
