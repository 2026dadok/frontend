# 1장. 리액트 다시 떠올리기

이 장은 **우리 프로젝트 코드를 예시로** 리액트를 처음부터 다시 정리해요. 이 장만 이해하면 나머지 코드는 전부 이 내용의 조합이에요.

---

## 1. 컴포넌트: 화면 조각을 돌려주는 함수

리액트에서 화면은 **컴포넌트**라는 함수들로 만들어요. 함수가 화면 모양을 `return` 하면 그게 화면에 그려져요.

```jsx
// src/pages/myPage/MyPage.jsx
const StatCard = ({ icon, label, value }) => (
  <div className="mp-stat">
    <Icon name={icon} size={50} strokeWidth={1.4} className="mp-stat-icon" />
    <div>
      <p>{label}</p>
      <strong>{value}</strong>
    </div>
  </div>
);
```

- 마이페이지의 통계 카드 하나를 만드는 함수예요.
- 이름은 **반드시 대문자로 시작**해요. 소문자(`div`)는 HTML 태그, 대문자(`StatCard`)는 우리가 만든 컴포넌트라는 표시예요.
- 쓸 때는 HTML 태그처럼 써요: `<StatCard icon="clock" label="총 독서 시간" value="152시간" />`

작은 조각을 모아 큰 조각을 만들어요. `MyPage` 안에 `StatCard`가 4개 들어가고, `App` 안에 `MyPage`가 들어가는 식이에요.

## 2. JSX: 자바스크립트 안에 쓰는 HTML

`return` 뒤의 HTML처럼 생긴 것을 **JSX**라고 해요. HTML과 비슷하지만 규칙이 몇 개 달라요.

| 규칙 | 예시 | 설명 |
|---|---|---|
| `class` 대신 `className` | `<div className="mp-stat">` | `class`는 자바스크립트 예약어라서요 |
| 값을 넣을 땐 중괄호 | `<p>{label}</p>` | `{}` 안은 자바스크립트예요 |
| 태그는 꼭 닫기 | `<img src={a} />` | `/`를 빼면 오류예요 |
| 부모는 하나만 | `<>...</>` | 묶을 태그가 필요 없으면 빈 태그(Fragment)를 써요 |
| 스타일은 객체로 | `style={{ width: 100 }}` | 바깥 `{}`는 JSX, 안쪽 `{}`는 객체예요 |
| 주석 | `{/* 주석 */}` | JSX 안에서는 이렇게 써요 |

### 조건에 따라 보여 주기

```jsx
{data && <div className="mp-column">...</div>}        // data 가 있을 때만 그린다
{book ? <img src={book.cover} /> : <p>책이 없어요</p>}  // 있으면 앞, 없으면 뒤
```

- `A && B`: A가 참일 때만 B를 그려요. 이 프로젝트에서 "불러오기 전에는 안 그리기"에 자주 써요.
- `A ? B : C`: A가 참이면 B, 아니면 C예요.

### 목록 그리기

```jsx
{data.locked.map((item) => (
  <Achievement key={item.id} item={item} />
))}
```

- `map`은 배열의 각 항목을 다른 값으로 바꿔요. 여기서는 데이터를 화면 조각으로 바꿔요.
- **`key`는 꼭 넣어야 해요.** 항목이 바뀌었을 때 리액트가 어떤 것이 어떤 것인지 알아보는 이름표예요. 겹치지 않는 값(id)을 써요.

## 3. props: 부모가 자식에게 주는 값

```jsx
<StatCard icon="clock" label="총 독서 시간" value={formatHours(data.stats.minutes)} />
```

`icon`, `label`, `value`가 **props**예요. 자식은 함수의 인자로 받아요.

```jsx
const StatCard = ({ icon, label, value }) => ( ... )
```

### 함수도 props로 줄 수 있어요

버튼을 눌렀을 때 **무엇을 할지는 부모가 정할 때** 자주 써요.

```jsx
// 부모: 책을 누르면 상세 화면을 열어라
<BookList onOpen={openBook} />

// 자식: 언제 누르는지만 안다
<button onClick={() => onOpen(b)}>
```

이름이 `on...`으로 시작하는 props는 대부분 이런 함수예요.

### children: 태그 사이에 넣은 내용

```jsx
// src/pages/auth/components/AuthLayout.jsx
const AuthLayout = ({ children }) => (
  <div className="page-background">
    ...
    <div className="auth-content">{children}</div>
  </div>
);

// 쓰는 곳
<AuthLayout>
  <div className="login-form">...</div>   {/* 이 부분이 children */}
</AuthLayout>
```

바깥 틀은 같고 안쪽 내용만 다를 때 써요. 로그인과 회원가입이 같은 틀을 쓰는 방법이에요.

## 4. 자주 나오는 자바스크립트 문법

리액트가 아니라 자바스크립트 문법이에요. 코드 곳곳에 나와요.

```js
// 화살표 함수
const add = (a, b) => a + b;              // 바로 값을 돌려준다
const add2 = (a, b) => { return a + b; }; // 중괄호를 쓰면 return 이 필요하다

// 구조 분해: 객체나 배열에서 값 꺼내기
const { ok, data } = await login(id, pw);  // result.ok, result.data
const [count, setCount] = useState(0);     // 배열의 0번, 1번

// 스프레드(...): 펼쳐서 복사하기
const next = { ...prev, name: "새 이름" };  // prev 를 복사하고 name 만 바꾼다
const list2 = [item, ...list];             // 맨 앞에 항목을 추가한 새 배열

// ?. : 없으면 오류 대신 undefined
location.state?.book       // state 가 없어도 오류가 안 난다

// ?? : 왼쪽이 null/undefined 일 때만 오른쪽
localStorage.getItem("token") ?? ""

// 템플릿 문자열: 백틱(`) 안에 ${값}
`${book.title} 상세 보기`

// async/await: 기다려야 하는 작업
const load = async () => {
  const res = await fetch("/users/my_page");  // 응답이 올 때까지 기다린다
  const data = await res.json();
};
```

`||`와 `??`의 차이도 알아 두세요. `a || b`는 a가 `0`, `""`, `false`여도 b를 쓰고, `a ?? b`는 a가 `null`이나 `undefined`일 때만 b를 써요.

## 5. state: 바뀌면 화면이 다시 그려지는 값

리액트의 핵심이에요. **일반 변수는 바꿔도 화면이 안 바뀌고, state를 바꾸면 화면이 다시 그려져요.**

```jsx
const [goal, setGoal] = useState("00:30");
//     값     바꾸는 함수         처음 값
```

- `goal`을 읽어서 화면에 쓰고, 바꿀 때는 **반드시 `setGoal("01:00")`** 으로 해요.
- `goal = "01:00"`처럼 직접 바꾸면 화면이 안 바뀌어요.

### "다시 그린다"는 뜻

state가 바뀌면 리액트는 **컴포넌트 함수를 처음부터 다시 실행**해요. 함수 안의 일반 변수는 매번 새로 계산돼요. 그래서 이런 코드가 가능해요.

```jsx
const goalSeconds = toSeconds(goal);        // goal 이 바뀔 때마다 자동으로 다시 계산
const reached = elapsed >= goalSeconds;     // state 로 만들 필요가 없다
```

**다른 state로 계산할 수 있는 값은 state로 만들지 않아요.**

### 객체와 배열은 새로 만들어서 넣기

```jsx
setForm((prev) => ({ ...prev, [key]: value }));   // ○ 복사한 새 객체
form.name = "새 이름"; setForm(form);              // × 같은 객체라 변화를 모른다
```

리액트는 "다른 객체인가?"로 변화를 판단해요. 그래서 코드에 `...prev`가 많이 나와요.

### 이전 값으로 계산할 때는 함수를 넣기

```jsx
setSecondsLeft((prev) => Math.max(0, prev - 1));  // prev 는 항상 최신 값
```

타이머처럼 시간이 지난 뒤 실행되는 코드에서는 꼭 이렇게 써요. `setSecondsLeft(secondsLeft - 1)`로 쓰면 예전 값을 계속 읽을 수 있어요.

### 처음 값 계산이 무거울 때

```jsx
const [reviews, setReviews] = useState(() => getReviews(book.id));
```

함수를 넣으면 **처음 한 번만** 실행돼요. localStorage를 읽는 코드에 이렇게 썼어요.

## 6. useEffect: 화면을 그린 다음에 할 일

서버에서 데이터 받아오기, 타이머 시작, 이벤트 등록처럼 **화면 그리기 말고 다른 일**을 할 때 써요.

```jsx
useEffect(() => {
  // 할 일
  return () => {
    // 뒷정리 (없어도 됨)
  };
}, [의존값]);
```

마지막 배열이 **언제 실행할지**를 정해요.

| 배열 | 실행 시점 |
|---|---|
| `[]` | 화면에 처음 나타날 때 한 번 |
| `[goal]` | 처음 + `goal`이 바뀔 때마다 |
| 없음 | 그릴 때마다 (거의 안 써요) |

**뒷정리 함수**는 화면에서 사라질 때, 또는 다음 실행 직전에 돌아요. 타이머를 끄거나 이벤트를 제거해요.

### 패턴 1: 서버에서 불러오기

이 프로젝트에 가장 많이 나오는 모양이에요.

```jsx
// src/pages/myPage/MyPage.jsx
useEffect(() => {
  let alive = true;
  fetchMyPage().then((result) => {
    if (!alive) return;     // 이미 화면을 떠났으면 무시
    setData(result);
  });
  return () => {
    alive = false;          // 화면을 떠나면 표시
  };
}, []);
```

응답이 오기 전에 다른 화면으로 가 버리면, 없어진 화면의 state를 바꾸게 돼요. `alive`로 그걸 막아요.

### 패턴 2: 타이머

```jsx
// src/pages/auth/useEmailTimer.js
useEffect(() => {
  if (!codeSent) return undefined;           // 아직 안 보냈으면 시작 안 함
  const id = setInterval(() => { ... }, 1000);
  return () => clearInterval(id);            // 꼭 꺼야 한다
}, [codeSent]);
```

### 패턴 3: 문서 전체 이벤트

```jsx
// src/hooks/useEscape.js
useEffect(() => {
  const onKey = (e) => e.key === "Escape" && onClose();
  document.addEventListener("keydown", onKey);
  return () => document.removeEventListener("keydown", onKey);
}, [onClose]);
```

## 7. useRef: 바뀌어도 다시 그리지 않는 값

```jsx
const timer = useRef(null);
timer.current = setTimeout(...);   // .current 로 읽고 쓴다
```

state와 달리 **바꿔도 화면을 다시 그리지 않아요.** 두 가지 용도로 써요.

1. **값 기억하기**: 타이머 번호처럼 화면과 상관없는 값 (`useToast`)
2. **실제 HTML 요소 잡기**: `<input ref={inputRef} />`로 잡아서 `inputRef.current.click()` 처럼 직접 조작 (`ImagePencil`의 파일 선택)

## 8. useMemo, useCallback: 결과를 기억해 두기

```jsx
// 서재 목록을 tab 이나 version 이 바뀔 때만 다시 읽는다
const books = useMemo(() => (tab === "my" ? getMyLibrary() : getSharedLibrary()), [tab, version]);

// 함수 자체를 기억한다 (다른 훅의 의존값으로 쓸 때 필요)
const genreLoader = useCallback((page) => fetchGenreBooks(genre, page), [genre]);
```

- `useMemo`: 계산 **결과**를 기억해요.
- `useCallback`: **함수**를 기억해요.

컴포넌트 안의 함수는 다시 그릴 때마다 새로 만들어져요. 그걸 `useEffect`의 의존값으로 쓰면 매번 다시 실행되니까, `useCallback`으로 묶어요.

## 9. 커스텀 훅: 내가 만든 훅

`use`로 시작하는 함수 안에 훅들을 모은 거예요. **여러 화면에 똑같이 들어가는 코드**를 뽑아내요.

```jsx
// src/hooks/useToast.js
const useToast = () => {
  const [toast, setToast] = useState("");
  const timer = useRef(null);

  useEffect(() => () => clearTimeout(timer.current), []);

  const showToast = useCallback((message, ms = 2000) => {
    clearTimeout(timer.current);
    setToast(message);
    timer.current = setTimeout(() => setToast(""), ms);
  }, []);

  return [toast, showToast];
};
```

```jsx
// 쓰는 곳: 두 줄로 끝난다
const [toast, showToast] = useToast();
<Toast message={toast} />
```

훅에는 규칙이 두 개 있어요.
- 컴포넌트나 다른 훅의 **맨 위에서만** 불러요. 
- `if`나 반복문 **안에서 부르면 안 돼요.** 부르는 순서가 항상 같아야 해요.

## 10. 이벤트와 입력칸

```jsx
<button type="button" onClick={handleLogin}>로그인</button>
```

`onClick={handleLogin}`은 **함수를 넘기는 것**이고, `onClick={handleLogin()}`은 그릴 때 **바로 실행**해 버리니 틀려요. 인자가 필요하면 `onClick={() => openBook(b)}`로 감싸요.

### 입력칸은 state와 연결해요

```jsx
const [email, setEmail] = useState("");
<input value={email} onChange={(e) => setEmail(e.target.value)} />
```

입력칸의 값이 항상 state와 같게 유지돼요. 이렇게 만든 입력칸을 **제어 컴포넌트**라고 불러요.

### 자주 쓰는 이벤트 함수

```jsx
<form onSubmit={(e) => { e.preventDefault(); finish(); }}>  // 새로고침을 막는다
<button onClick={(e) => { e.stopPropagation(); ... }}>      // 부모의 클릭으로 안 번지게
```

`e.nativeEvent.isComposing`은 한글을 조합하는 중인지 알려 줘요. 한글 입력 중 Enter가 두 번 눌리는 문제를 막을 때 써요.

## 11. 페이지 이동: react-router

한 페이지 안에서 주소에 따라 화면만 바꿔요.

```jsx
// src/App.jsx
<BrowserRouter>
  <Routes>
    <Route path="/home" element={<Home />} />      // 주소 → 화면
    <Route element={<Layout />}>                   // 공통 틀 안에 넣기
      <Route path="/mypage" element={<MyPage />} />
    </Route>
    <Route path="*" element={<Navigate to="/" replace />} />  // 없는 주소
  </Routes>
</BrowserRouter>
```

| 도구 | 하는 일 | 예시 |
|---|---|---|
| `<Link to="...">` | 누르면 이동하는 링크 | `<Link to={PATHS.mypageEdit}>` |
| `<NavLink>` | 현재 주소면 표시가 붙는 Link | 사이드바 메뉴 |
| `useNavigate()` | 코드로 이동 | `navigate(PATHS.timer, { state: { book } })` |
| `useLocation()` | 현재 주소 정보 | `location.state?.book` |
| `useSearchParams()` | `?tab=my` 읽기 | `params.get("tab")` |
| `<Outlet />` | 틀 안에서 자식 화면이 들어갈 자리 | `Layout` |
| `<Navigate />` | 그리자마자 이동 | 없는 주소 처리 |

`navigate(주소, { state: { book } })`는 **보이지 않게 값을 함께 넘겨요.** 서재에서 타이머로 책 정보를 넘길 때 써요.

## 12. 서버와 브라우저 저장소

### fetch: 서버에 요청

```js
const res = await fetch("/auth/login", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ ID, passward }),   // 객체 → 글자
});
const data = await res.json();              // 글자 → 객체
```

`res.ok`는 응답 코드가 200번대면 `true`예요.

### localStorage: 브라우저에 저장

```js
localStorage.setItem("token", accessToken);     // 저장 (글자만 가능)
localStorage.getItem("token");                  // 읽기 (없으면 null)
localStorage.setItem("user", JSON.stringify(profile));  // 객체는 글자로 바꿔서
JSON.parse(localStorage.getItem("user"));               // 읽을 때 다시 객체로
```

브라우저를 꺼도 남아 있어요. 다른 사람이나 다른 컴퓨터와는 공유되지 않아요. 그래서 지금 서재와 감상문은 **내 브라우저에만** 저장돼 있고, 백엔드를 연결하면 서버로 옮겨야 해요.

## 13. import와 export

```js
export default Home;                 // 파일의 대표. 하나만 가능
import Home from "./pages/home/Home";     // 이름을 마음대로 정할 수 있다

export const getMe = () => { ... };  // 이름 붙여 내보내기. 여러 개 가능
import { getMe } from "./bookStore";      // 같은 이름으로 중괄호 안에

import xpIcon from "../../images/icon-xp.png";  // 이미지는 주소(글자)가 들어온다
import "./Home.css";                            // CSS 는 불러오면 전체에 적용된다
```

**CSS는 화면 하나에만 적용되는 게 아니에요.** 한 번 불러오면 앱 전체에 적용돼요. 그래서 파일마다 `mp-`, `rk-`, `tm-`처럼 앞글자를 붙여 겹치지 않게 했어요.

## 14. 이 프로젝트만의 약속 세 가지

코드에 계속 나오니까 미리 알아 두세요.

### ① 화면 크기 맞추기 (`useFitScale`)

디자인은 가로 1419px로 만들어졌어요. 창이 더 작으면 **CSS `zoom`으로 화면 전체를 줄여요.**

```jsx
const scale = useFitScale();                    // 예: 0.8
<div className="bs-stage" style={{ "--s": scale }}>
```
```css
.bs-stage { zoom: var(--s, 1); }
```

`--s`는 CSS 변수예요. 자바스크립트에서 값을 넣고 CSS에서 읽어요.

### ② 백엔드가 없어도 화면이 나오게

아직 백엔드가 없을 때를 위해, 요청이 실패하면 임시값(`MOCK_...`)이나 브라우저 저장소 값을 보여 줘요. `TODO`가 붙어 있고 백엔드 연결 후 지울 코드예요.

### ③ `TODO` 주석

"나중에 해야 할 일"이라는 표시예요. 프로젝트 전체에서 `TODO`를 검색하면 남은 일이 나와요.
