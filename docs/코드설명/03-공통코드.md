# 3장. 공통 코드

앱 전체가 같이 쓰는 파일들이에요.

## 설정 파일

### `index.html`

브라우저가 처음 받는 유일한 HTML이에요. `<div id="root"></div>` 빈 칸 하나와 `main.jsx`를 부르는 줄이 전부예요. 화면은 전부 리액트가 이 칸 안에 그려요.

### `package.json`

- `scripts`: `npm run dev`(개발 서버), `npm run build`(배포용 빌드), `npm run lint`(코드 검사), `npm run preview`(빌드 결과 보기)
- `dependencies`: 앱에 들어가는 라이브러리. `react`, `react-dom`, `react-router-dom` 세 개뿐이에요.
- `devDependencies`: 개발할 때만 쓰는 도구. `vite`, `eslint` 등이에요.

### `vite.config.js`

개발 서버 설정이에요. **프록시**가 핵심이에요. 프록시는 브라우저 요청을 받아 다른 서버로 대신 전달해 주는 기능이에요.

```js
const BACKEND_PATHS = ['/auth', '/library', '/quests', '/users', '/bookstore', '/books', '/times', '/main']
```
백엔드로 넘길 주소 앞부분 목록이에요.

```js
const env = loadEnv(mode, '.', '')
```
`.env.local` 파일을 읽어요. `VITE_`로 시작하지 않는 값은 브라우저 코드에 들어가지 않아서 키가 노출되지 않아요.

```js
'/yes24': {
  target: 'https://apis.yes24.com',
  changeOrigin: true,
  rewrite: (path) => path.replace(/^\/yes24/, ''),
  headers: { 'X-Api-Key': env.YES24_API_KEY ?? '' },
},
```
브라우저가 `/yes24/v1/...`로 요청하면, `/yes24`를 떼고 키를 붙여서 YES24로 보내요. 키가 브라우저에 드러나지 않아요.

```js
if (env.BACKEND_URL) {
  for (const path of BACKEND_PATHS) {
    proxy[path] = {
      target: env.BACKEND_URL,
      changeOrigin: true,
      bypass: (req) => (req.headers.accept?.includes('text/html') ? '/index.html' : undefined),
    }
  }
}
```
`BACKEND_URL`이 있으면 API 요청을 백엔드로 넘겨요. `bypass`는 **주소창에서 들어온 화면 이동은 넘기지 않는** 장치예요. 화면 주소 `/auth/log_page`와 API `/auth/login`의 앞부분이 같아서 필요해요. 브라우저가 페이지를 열 때는 `Accept: text/html`을 보내니까 그걸로 구분해요.

### `eslint.config.js`

`npm run lint`로 코드 실수를 찾는 규칙이에요. 안 쓰는 변수, 훅 규칙 위반 등을 잡아 줘요.

### `src/global.css`

Pretendard 글꼴을 인터넷에서 불러오고, 모든 요소의 기본 여백을 없애요. `.page-background`는 로그인 화면들의 회색 배경이에요.

## 시작점

### `src/main.jsx`

```jsx
createRoot(document.getElementById('root')).render(<App />)
```
`#root` 칸에 `<App />`을 그리라는 뜻이에요. 앱 전체의 시작이에요.

### `src/routes.js`

```js
export const PATHS = { guest: "/auth/guest_page", main: "/home", ... };
```
주소를 한곳에 모아 둬요. 주소가 바뀌어도 여기만 고치면 돼요. 코드에서는 `PATHS.main`처럼 써요.

### `src/App.jsx`

주소와 화면의 연결표예요.

**`SignupPage`, `LoginPage`, `FindPage`**: 화면 컴포넌트를 감싸는 작은 컴포넌트예요. 화면은 "가입이 끝났다"만 알리고, 어디로 갈지는 여기서 정해요.

**`LoginPage`의 `onLoginSuccess`**: 로그인이 성공하면 실행돼요.
```jsx
const { accessToken, refreshToken, ...profile } = data;  // 토큰과 나머지를 나눈다
localStorage.setItem("token", accessToken);              // 이후 API 호출에 쓴다
if (refreshToken) localStorage.setItem("refreshToken", refreshToken);
localStorage.setItem("user", JSON.stringify(profile));   // 내 정보
navigate(PATHS.main, { replace: true });                 // 홈으로 (뒤로 가기로 못 돌아오게)
```

**`RequireAuth`**: 토큰이 없으면 로그인 화면으로 보내는 문지기예요. **지금은 안 쓰고 있어요.** 개발 중이라 꺼 뒀고, 완성 전에 켜야 해요.

**`App`**: `Routes` 안에 전체 주소가 있어요.
- `<Route element={<Layout />}>` 안의 화면은 왼쪽에 사이드바가 붙어요.
- 타이머와 로그인 쪽은 그 바깥이라 사이드바가 없어요.
- `path="*"`는 없는 주소를 첫 화면으로 보내요.

## `src/api/`: 서버 호출 도구

### `client.js`: 모든 서버 호출의 공통 도구

**`authHeaders()`**: 저장해 둔 토큰으로 `Authorization: Bearer 토큰` 헤더를 만들어요. 백엔드는 이걸로 누가 보낸 요청인지 알아요.

**`requestServer(method, url, body)`**: 실제로 `fetch`를 해요.
```js
try {
  const res = await fetch(url, { method, headers: {...}, body: JSON.stringify(body) });
  const data = await res.json().catch(() => null);  // JSON 이 아니면 null
  return { ok: res.ok, data };
} catch {
  return { ok: false, data: null };                 // 서버가 꺼져 있을 때
}
```
**오류를 던지지 않고 항상 `{ ok, data }`를 돌려줘요.** 그래서 부르는 쪽이 `if (!ok)`만 확인하면 돼요.

**`pick(obj, ...names)`**: 후보 이름 중 값이 있는 첫 번째를 돌려줘요. `pick(raw, "name", "user_name")`처럼 써요. 백엔드 필드 이름이 아직 안 정해져서 만든 임시 도구예요. 정해지면 지워요.

### `auth.js`: 로그인 관련 API

각 함수가 API 하나예요.

| 함수 | API |
|---|---|
| `login(ID, passward)` | `POST /auth/login` |
| `sendEmailCode(email, purpose)` | `POST /auth/email_send` |
| `verifyEmailCode(email, code)` | `POST /auth/email_verify` |
| `findId(email)` | `POST /auth/find_id` |
| `signup(payload)` | `POST /auth/signup` |
| `checkId(ID)` | `GET /auth/check_id` |
| `requestPasswordReset(email)` | `POST /auth/rest-passwrod` |
| `resetPassword(token, newpassward)` | `POST /auth/pw_reset` |

`passward`는 오타처럼 보이지만 **명세서 철자 그대로**예요. 고치면 서버가 못 알아들어요.

- `post(url, body)`: 파일 안에서만 쓰는 도우미예요. `requestServer`와 비슷한데 토큰을 안 붙여요. 로그인 전이라 토큰이 없으니까요.
- `EMAIL_PURPOSE`: 인증번호를 보내는 목적 값이에요. 백엔드와 값을 확인해야 해요.
- `toExpireSeconds(expiresIn, fallback)`: 서버가 준 만료 시간이 이상하면(숫자가 아니거나 1시간 초과) 기본값을 써요.

### `attendance.js`: 일일 출석

어느 화면으로 들어오든 오늘 첫 방문이면 출석을 보내요.

**`checkAttendance()`**
1. 오늘 날짜를 `2026-11-07` 모양으로 만들어요. (`toLocaleDateString("sv-SE")`는 스웨덴 형식이 이 모양이라 쓰는 요령이에요.)
2. localStorage에 오늘 날짜가 있으면 끝이에요. 이미 출석한 거니까요.
3. `POST /quests/attendance`를 보내요.
4. 성공하면 오늘 날짜를 저장하고 XP 알림을 띄워요.

**`ensureAttendance()`**: `Layout`과 `Home`이 동시에 부를 수 있어요. `inflight`에 진행 중인 요청을 기억해서 **한 번만** 보내요.

### `myImages.js`: 내 프로필·배경 사진 저장소

마이페이지에서 사진을 바꾸면 주간 경쟁과 공동서재에도 바로 반영돼야 해서, 사진을 한곳에 모았어요.

- **`keyOf(kind)`**: `myImage:아이디:profile` 같은 저장 이름을 만들어요. 사용자마다 따로 저장돼요.
- **`getMyImage(kind)`**: 저장된 사진을 읽어요.
- **`setMyImage(kind, url)`**: 저장하고 **`listeners`에게 알려요.** 빈 값이면 지워요.
- **`subscribeMyImage(listener)`**: "사진이 바뀌면 나한테 알려 줘"라고 등록해요. 해제 함수를 돌려줘요.
- **`shrinkImage(kind, file)`**: localStorage는 용량이 작아서 사진을 줄여요. `canvas`에 작게 그린 다음 글자(data URL)로 바꿔요. 프로필은 256px, 배경은 1600px까지 줄여요.

이 "등록해 두면 알려 주는" 방식을 **구독(subscribe)** 이라고 불러요. `xpToastBus`도 같은 방식이에요.

## `src/hooks/`: 공통 훅

### `useFitScale.js`: 화면 크기 맞추기

```js
const calcScale = (fitHeight) =>
  Math.min(1, fitHeight ? window.innerHeight / DESIGN_H : 1, (window.innerWidth - SIDEBAR_W) / DESIGN_W);
```
디자인 크기(1419 × 967)와 창 크기를 비교해 **줄일 비율**을 구해요. `Math.min(1, ...)`이라 1보다 커지진 않아요. 창을 키워도 확대되지 않아요.

- `useEffect`에서 창 크기가 바뀔 때마다 다시 계산해요.
- `fitHeight: false`면 가로만 맞춰요. 위아래로 스크롤되는 페이지(마이페이지, 감상문, 인용구)에 써요.

### `useMyImage.js`

`myImages.js`를 컴포넌트에서 쓰기 쉽게 감싼 훅이에요. `const image = useMyImage("profile")` 한 줄이면, 사진이 바뀔 때 화면도 자동으로 다시 그려져요.

### `useToast.js`

알림 문구예요. 1장 9절에 설명이 있어요. `showToast("저장했어요.")` 하면 2초 뒤 사라져요. 새 알림이 오면 이전 타이머를 지워서 일찍 사라지지 않아요.

### `useEscape.js`

Esc를 누르면 `onClose`를 불러요. 인용구와 감상문 팝업이 같이 써요.

## `src/components/`: 공통 컴포넌트

### `layouts/layout.jsx`

사이드바가 있는 화면들의 틀이에요.
```jsx
<div className="app-layout">
  <XpToast />                     {/* XP 알림 (모든 화면 공통) */}
  <Sidebar />
  <main className="app-layout-main">
    <Outlet />                    {/* 여기에 각 화면이 들어간다 */}
  </main>
</div>
```
`useEffect`에서 `ensureAttendance()`로 출석을 보내요.

`layout.css`: 사이드바가 `position: fixed`라 자리를 차지하지 않으니, 본문에 `margin-left: 103px`를 줘서 겹치지 않게 해요.

### `sidebars/sidebar.jsx`

```jsx
const MENUS = [{ label: "마이페이지", to: PATHS.mypage, icon: mypageIcon }, ...];
const linkClass = ({ isActive }) => (isActive ? "sidebar-item active" : "sidebar-item");
```
메뉴를 배열로 만들고 `map`으로 그려요. `NavLink`는 현재 주소와 맞는지(`isActive`)를 알려 줘요. 그래서 현재 메뉴만 회색 배경이 돼요. `/mypage/edit`에서도 `/mypage`가 켜져요.

### `xpToast/xpToastBus.js`

XP 알림을 어디서든 띄우게 해 주는 **전달 통로**예요.
```js
const listeners = new Set();
export const showXpToast = ({ title, xp }) => {
  listeners.forEach((listener) => listener({ title, xp, key: Date.now() }));
};
export const subscribeXpToast = (listener) => { ...등록, 해제 함수 돌려줌 };
```
`attendance.js`처럼 컴포넌트가 아닌 파일에서도 `showXpToast()`를 부를 수 있어요.

### `xpToast/XpToast.jsx`

`useEffect`에서 통로를 구독해요. 소식이 오면 state에 넣고 3초 뒤 지워요.

`maskImage`는 이미지 모양대로 잘라 내는 CSS예요. PNG를 마스크로 쓰면 아이콘을 원하는 색으로 칠할 수 있어요.

### `goalTime/goalTime.js`, `goalTime/GoalTimeInput.jsx`

목표 시간을 시 : 분으로 입력하는 칸이에요. 타이머와 회원정보 수정이 같이 써요.

**`TIME_PARTS`**: 칸 목록과 최대값이에요. (시 23, 분 59)

**`normalizeGoalTime("0:5")`** → `"00:05"`: 입력 중인 값을 정리해요.

**`GoalTimeInput`**은 이 프로젝트에서 가장 까다로운 입력칸이에요.

- `value`는 `"00:30"` 글자예요. `:`로 잘라서 칸마다 보여 줘요.
- `refs`: 칸들의 실제 요소를 기억해요. 다음 칸으로 포커스를 옮길 때 써요.
- `startValue`: 칸에 들어왔을 때의 값이에요. 첫 입력이 기존 값을 지우고 새로 시작하게 해요.
- `latest`: 가장 최근 값이에요. state는 다시 그려진 뒤에야 바뀌는데, 다음 칸으로 넘어가면 그보다 먼저 `onBlur`가 실행돼요. 그래서 ref에 최신 값을 따로 둬요.

**`type(index, e)`**: 글자가 입력될 때 실행돼요.
1. 숫자만 남겨요. (`replace(/\D/g, "")`)
2. 칸에 들어와 처음 친 글자면, 기존 값 사이에 끼어들었어도 커서 위치로 **새로 친 글자만** 골라내요. 22를 쳤는데 02가 되던 버그를 막는 부분이에요.
3. 뒤 두 자리만 남기고, 최대값을 넘으면 최대값으로 바꿔요.
4. 두 자리가 차면 다음 칸으로 포커스를 옮겨요.

**`onFocus`**: 전체 선택해서 바로 새로 칠 수 있게 해요.
**`onMouseUp`**: 마우스를 떼면 전체 선택이 풀리는 걸 막아요.
**`onBlur`**: 칸을 벗어나면 `5` → `05`로 앞에 0을 붙여요.

### `CompleteBadge.jsx`

책 표지에 붙는 '완독' 뱃지예요. `className`으로 위치와 크기를 정해요.
