# 4장. 로그인과 회원가입 (`src/pages/auth/`)

## 공통 부품 (`components/`)

### `AuthLayout.jsx`

로그인·회원가입·찾기 화면의 틀이에요. 왼쪽 분홍 영역에 나무 그림, 오른쪽 흰 영역에 로고와 내용(`children`)이 들어가요. `pink_fir`, `pink_sec`, `white_fir`, `white_sec` 네 개의 사각형을 겹쳐서 가운데의 둥근 곡선을 만들어요.

### `AuthLayout2.jsx`

생년월일과 목표 시간 화면의 틀이에요. 분홍 틀 안에 흰 판이 있고 왼쪽 아래에 두더지가 있어요. `footer` props로 버튼을 받아요.

### `LineInput.jsx`

밑줄만 있는 입력칸이에요.
```jsx
export const LineInput = ({ placeholder, type = "text", value, onChange, onKeyDown }) => (
  <input className="line-input" ... onChange={(e) => onChange(e.target.value)} />
);
```
`type = "text"`는 안 넘기면 쓰는 기본값이에요. `onChange`에 이벤트 대신 **글자를 바로** 넘겨요. 그래서 쓰는 쪽이 `onChange={setEmail}`로 짧게 쓸 수 있어요.

### `Select.jsx`의 `DateSelect`

직접 만든 드롭다운이에요.
- `open` state로 목록을 열고 닫아요.
- `wrapRef`로 자기 영역을 잡아요. `useEffect`에서 문서 전체 클릭을 감시해서, **자기 바깥을 누르면** 닫아요.
- 값이 없으면 `label`(`HRS`)을 보여 줘요: `{value ?? label}`

### `TripleSelectStep.jsx`

드롭다운 여러 개와 버튼으로 된 화면이에요. 생년월일(3칸)과 목표 시간(2칸)이 같이 써요.
```jsx
const [values, setValues] = useState(
  () => Object.fromEntries(fields.map((f) => [f.label, null]))
);
```
`fields`에서 `{ HRS: null, MIN: null }` 같은 처음 값을 만들어요.

**`handleClick`**: `validate`가 있으면 검사하고, 틀리면 `alert`, 맞으면 `onSubmit(values)`를 불러요.

### `range.js`

`range(1, 3)` → `["1", "2", "3"]`. 드롭다운 숫자 목록을 만들어요.

## 공통 훅: `useEmailTimer.js`

회원가입, 아이디 찾기, 비밀번호 찾기에 **똑같이 들어가던 시계 코드**를 뽑아냈어요.

| 돌려주는 값 | 의미 |
|---|---|
| `codeSent` | 인증번호를 보냈는지 |
| `secondsLeft` | 인증 남은 시간(초) |
| `resendCooldown` | 다시 받기까지 남은 시간 |
| `timeText` | `04:59` 모양 글자 |
| `sendLabel` | 버튼 글자 (`인증번호 받기`, `다시 받기 (58초)`, `다시 받기`) |
| `startTimer(expiresIn)` | 보낸 직후에 부르는 함수 |

`useEffect` 안의 `setInterval`이 1초마다 두 시간을 1씩 줄여요. `Math.max(0, prev - 1)`이라 0 아래로 안 내려가요.

## 로그인: `LoginForm.jsx`

- `name`(아이디), `passwd` state가 입력칸과 연결돼 있어요.
- **`validate()`**: 비어 있는지, 길이가 넘치는지 검사해요. `name.replace(/\s/g, "")`는 공백을 뺀 길이를 보려는 거예요.
- **`handleLogin()`**: 검사 → `login()` 호출 → 성공하면 `onLoginSuccess(data)`로 부모(`App.jsx`)에게 알려요.
- **`handleEnter(e)`**: 비밀번호 칸에서 Enter를 누르면 로그인해요.

토큰 저장은 `App.jsx`의 `LoginPage`가 해요. 화면은 입력만, 저장은 부모가 맡아요.

## 회원가입 (여러 단계)

### `SignupFlow.jsx`: 단계 관리자

```
signup(아이디·비밀번호) → emailVerify(이메일 인증) → birth(생년월일) → goalTime(목표 시간) → 서버로 전송
```

- `step` state로 현재 단계를 기억해요. 주소는 안 바뀌고 화면만 바뀌어요.
- `signupData` state에 **단계마다 입력한 값을 모아요.** 각 `handle...Next` 함수가 값을 합치고 다음 단계로 넘겨요.
  ```js
  setSignupData((prev) => ({ ...prev, ...formData }));
  setStep("emailVerify");
  ```
- **`handleGoalNext`**: 마지막 단계예요. 모은 값으로 `payload`를 만들어 `signup()`을 불러요. 목표 시간은 `` `${values.HRS}:${values.MIN}` ``으로 초 없이 보내요. 실패하면 처음 단계로 돌아가요.

### `SignupForm.jsx`: 1단계

- **`validate()`**: 빈 칸, 길이, 비밀번호 일치를 검사해요.
- **`handleNext()`**: 검사 후 **`checkId()`로 아이디 중복을 확인해요.** `data?.available === false`일 때만 막아요. 서버가 없으면 `data`가 `null`이라 그냥 넘어가요.

### `EmailVerify.jsx`: 2단계

- **`handleStartVerify()`**: 이메일 확인 → `sendEmailCode()` → 성공하면 `startTimer()`.
- **`handleCreateAccount()`**: 보냈는지, 시간이 남았는지, 6자리인지 검사 → `verifyEmailCode()` → 성공하면 `onNext({ email })`.

### `AuthBirth.jsx`: 3단계

`fields`에 연·월·일 목록을 만들어 `TripleSelectStep`에 넘겨요.

**`isValidDate(y, m, d)`**: 2월 30일 같은 날짜를 걸러요. 자바스크립트 `new Date(2026, 1, 30)`은 오류 없이 3월 2일이 돼요. 그래서 **만든 날짜의 연·월·일이 입력과 같은지** 비교해요. 미래 날짜도 막아요.

### `AuthGoalTime.jsx`: 4단계

시·분 목록을 만들어요. **`validate`**: 둘 다 골랐는지, `00:00`이 아닌지 봐요.

## 아이디·비밀번호 찾기

### `FindAccount.jsx`: 탭

`tab` state로 '아이디 찾기'와 '비밀번호 찾기'를 바꿔요. 주소에 `?pageGubun=password`가 있으면 비밀번호 탭부터 열어요.

### `FindId.jsx`

1. **`handleStartVerify()`**: 인증번호를 보내요.
2. **`handleFindId()`**: 인증번호 확인 → `findId()` → `foundId`에 저장해요.
3. `foundId`가 있으면 결과 화면을 `return`해요. 이렇게 **중간에 `return`해서 다른 화면을 그리는** 방식을 자주 써요.

### `FindPassword.jsx`

명세서 주소로 다시 만들었어요.

1. **`handleStartVerify()`**: `POST /auth/rest-passwrod`로 메일을 보내요.
2. **`handleVerify()`**: `POST /auth/email_verify`로 인증번호를 확인해요. 응답의 `token`을 저장해요. 없으면 인증번호를 대신 써요.
3. `token` state가 있으면 새 비밀번호 화면을 보여 줘요.
4. **`handleResetPassword()`**: 일치 검사 → `POST /auth/pw_reset` → 성공하면 로그인 화면으로 가요.

**백엔드 확인 필요:** `token`을 어디서 받는지 명세서에 없어요. 코드에 `TODO`로 남겨 뒀어요.
