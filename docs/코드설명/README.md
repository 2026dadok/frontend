## 어디까지 설명했나요

- **자바스크립트·JSX 파일**: 모든 파일을 다뤘고, 파일마다 컴포넌트와 함수가 무슨 일을 하는지 설명했어요. 어려운 부분은 코드를 직접 보여 줘요. 다만 한 줄씩 전부 풀지는 않았고, 입력칸 비우기 같은 아주 짧은 함수나 HTML 모양을 그대로 그리는 줄은 건너뛴 곳도 있어요. 모르는 줄이 나오면 물어보세요.
- **CSS 파일**: 양이 많고 대부분 크기·색 값이라, 파일별 역할과 기법 위주로 설명했어요.

## 읽는 요령

1. 설명서와 코드를 **나란히 열어 두세요.**
2. 화면을 하나 켜 놓고, 그 화면의 코드를 읽으세요.
3. 궁금한 값이 있으면 `console.log(값)`을 넣어 브라우저 콘솔에서 보세요.
4. 일부러 값을 바꿔 보세요. `useToast.js`의 `DEFAULT_MS`를 10000으로 바꾸면 알림이 오래 남아요. 이렇게 해 보는 게 가장 빨리 익혀져요.

## 공부 순서 추천

처음부터 큰 화면을 보면 어려워요. 쉬운 것부터요.

1. `CompleteBadge.jsx`, `LineInput.jsx`: props만 있는 가장 단순한 컴포넌트
2. `LoginForm.jsx`: state와 이벤트
3. `useToast.js`: 커스텀 훅
4. `WeeklyRank.jsx`: useEffect로 데이터 불러오기
5. `Timer.jsx`: state로 화면 바꾸기
6. `BookSearch.jsx`: 가장 복잡한 화면
