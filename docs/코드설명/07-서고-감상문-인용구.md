# 7장. 서고, 공동서재, 감상문, 인용구

## 서고: `src/pages/myLibrary/`

### `libraryApi.js`

**`fetchReadingLog()`**: 날짜별 읽은 시간을 읽어요. `{ "2026-10-26": 45 }` 모양이에요. 타이머가 여기에 쌓아요.

### `ReadingCalendar.jsx`: 독서 달력

1년을 53칸 × 7줄로 그려요. GitHub 잔디와 같은 모양이에요.

**`levelOf(minutes)`**: 읽은 시간을 진하기 단계로 바꿔요. 10분 미만은 0단계, 그 위로 올라가요. 90분부터는 30분마다 한 단계씩이고 최대 10단계예요.

**`colorOf(level)`**: 단계를 색으로 바꿔요. `hsl(345 52% 밝기%)`에서 단계가 높을수록 밝기가 낮아져 진해져요.

**`toKey(date)`**: 날짜를 `2026-10-26` 글자로 바꿔요. `log`에서 찾을 때 써요.

**`useMemo` 안의 칸 계산**:
```js
const jan1 = new Date(year, 0, 1);
const start = new Date(year, 0, 1 - ((jan1.getDay() + 6) % 7)); // 1월 1일이 든 주의 월요일
```
`getDay()`는 일요일이 0이라, `+ 6) % 7`로 월요일이 0이 되게 바꿔요. 그만큼 앞으로 가면 그 주 월요일이에요.

53주 × 7일을 돌면서 **올해가 아니면 `null`** 을 넣어요. `null` 칸은 점선 테두리 칸으로 그려요.

`monthLabels`: 각 달 1일이 몇 번째 주인지 계산해서 `1월`, `2월` 글자 위치를 정해요.

### `Library.jsx`

**계산하는 값들**

```js
const canvasW = Math.max(DESIGN_CANVAS_W, (useWindowWidth() - SIDEBAR_W) / scale);
const slotsPerPage = Math.max(1, Math.floor((booksAreaW + BOOK_GAP) / (BOOK_W + BOOK_GAP)));
```
창 너비로 **한 줄에 책이 몇 권 들어가는지** 계산해요. 창이 넓으면 더 많이 보여요.

```js
const tab = params.get("tab") === "shared" ? "shared" : "my";
```
탭은 state가 아니라 **주소(`?tab=shared`)** 에 있어요. 새로고침해도 유지돼요.

```js
const books = useMemo(() => (tab === "my" ? getMyLibrary() : getSharedLibrary()), [tab, version]);
```
`version`은 "다시 읽어라" 신호예요. 책을 지운 뒤 `setVersion((v) => v + 1)`로 올리면 목록을 다시 읽어요.

```js
const items = [...shown, null];   // null = 맨 끝의 + 칸
const pageItems = items.slice(currentPage * slotsPerPage, (currentPage + 1) * slotsPerPage);
```
`slice`로 지금 쪽의 칸만 잘라요.

**부품**

- **`MenuIcon`**: 메뉴 아이콘. `ICONS`에서 이름으로 골라요.
- **`Arrow`**: 이전/다음 화살표.
- **`useWindowWidth()`**: 창 너비를 state로 돌려주는 훅.

**함수**

| 함수 | 하는 일 |
|---|---|
| `switchTab(next)` | 나의 서재 ↔ 공동 서재. 주소를 바꾸고 필터와 쪽을 초기화 |
| `pickCategory(value)` | 장르 필터 고르기 |
| `goSearch()` | 검색어를 들고 책 검색으로 이동 |
| `openBook(book)` | 나의 서재: 메뉴 열기 / 공동 서재: 공동서재 페이지로 |
| `readNow(book)` | 타이머로 이동 |
| `writeReview(book)` | 감상문 쓰기로 이동 |
| `deleteBook(book)` | 확인 후 삭제 |

두 번째 `useEffect`는 메뉴 **바깥을 누르거나 Esc를 누르면** 닫아요. `e.target.closest(".lib-book-wrap, .lib-category")`는 누른 곳이 그 영역 안인지 찾아요.

`i >= 3 ? "flip" : ""`: 오른쪽 끝 책은 메뉴가 화면 밖으로 나가니까 왼쪽으로 열어요.

## 공동서재: `src/pages/sharedLibrary/SharedLibraryPage.jsx`

**`readPercent(value)`**: 주소의 `?me=100&friend=78` 값을 0~100으로 정리해요. **미리보기용**이고 백엔드 연결 후 지워요.

**`SharedLibraryView`**:
```js
const iWon = myPercent === 100 && friendPercent < 100;
const finished = myPercent === 100 && friendPercent === 100;
```
- 내가 먼저 완독하면 XP 알림 후 "승 리"를 보여 줘요.
- 둘 다 완독하면 "함께 읽기가 종료되었습니다" 알림을 띄워요.

XP 알림(3초)이 사라진 뒤 "승 리"가 나오게 타이머로 순서를 맞췄어요. 같은 자리라 겹치지 않게요.

**`SharedLibraryPage`**: `key={location.key}`로 주소가 바뀌면 새로 그려요.

내용 자체는 6장의 `SharedLibrary.jsx`를 그대로 써요.

## 감상문: `src/pages/review/`

### `format.js`

`formatDate("2026-09-20")` → `"2026. 9. 20"`

### `reviewApi.js`

- **`fetchMyCommentaries(id)`**: 내 감상문. 지금은 브라우저에서 읽어요.
- **`fetchFriendCommentaries()`**: 친구 감상문. **지금은 항상 빈 배열**이에요.
- **`DEMO_COMMENTARIES`**: 주소에 `?demo=1`을 붙이면 보이는 예시 데이터예요.

### `ReviewModals.jsx`: 팝업

- **`CloseButton`**: 닫기 버튼.
- **`Overlay`**: 어두운 배경과 가운데 팝업. `e.target === e.currentTarget`은 **배경을 직접 눌렀을 때만** 닫으라는 뜻이에요. 팝업 안을 누르면 닫히지 않아요.
- **`Arrow`**: 이전/다음 감상문 화살표.
- **`CommentaryDetailModal`**: 감상문 전체 보기. `onPrev`, `onNext`가 있을 때만 화살표를 그려요.
- **`CommentaryWriteModal`**: 감상문 쓰기. `maxLength`로 300자를 제한하고, 글자 수를 보여 줘요. 비어 있으면 완료 버튼이 꺼져요.

### `Review.jsx`

주소로 내용이 달라져요.
- `/review`: 내 감상문
- `/review?who=friend`: 친구 감상문
- `/review?write=1`: 쓰기 팝업을 바로 열기

**책 정하기**
```js
const [firstBook] = useState(() => getMyLibrary()[0] ?? getSharedLibrary()[0] ?? null);
const book = location.state?.book ?? firstBook;
```
넘겨받은 책이 없으면 서재의 첫 책을 써요. `useState`로 감싼 이유는, 그릴 때마다 localStorage를 읽으면 매번 **새 객체**가 되어 아래 `useMemo`와 `useEffect`가 계속 다시 돌기 때문이에요.

**일차 계산**
```js
const lastWritten = Math.max(0, ...entries.map((e) => e.day));   // 쓴 것 중 가장 큰 일차
const sinceStart = startIso ? daysSince(startIso) + 1 : 1;       // 시작한 지 며칠째
const total = Math.max(1, lastWritten, demo ? 0 : sinceStart);
days: Array.from({ length: total }, (_, i) => total - i)         // [5, 4, 3, 2, 1]
```
큰 일차가 먼저 나오게 거꾸로 만들어요.

**소개 다시 가져오기**: 서재에 소개가 없는 책은 YES24에서 찾아 저장해요.

**`updateIntroFade(el)`**: 소개 칸의 스크롤 위치로 위·아래 흐림 정도를 계산해 CSS 변수(`--top`, `--bottom`)에 넣어요. 글이 더 있는 쪽 가장자리가 흐려져요.

**`DayCard`**: N일차 카드. 글이 있으면 내용, 없으면 "이 감상문은 적지 않으셨어요..."와 쓰기 버튼이에요.

**`writtenDays`, `goPrev`, `goNext`**: 팝업에서 글이 있는 일차로만 넘어가게 해요. 끝이면 `null`이라 화살표가 안 나와요.

## 인용구 노트: `src/pages/quote/`

### `quoteStore.js`

인용구를 localStorage `quotes`에 저장해요.

| 함수 | 하는 일 |
|---|---|
| `getQuotes()` | 전체 읽기 |
| `addQuote({ book, page, text })` | 서버에 보내고 브라우저에도 저장 |
| `updateQuote(id, text)` | **서버가 성공해야만** 수정 |
| `removeQuote(id)` | **서버가 성공해야만** 삭제 |
| `toggleFavorite(id)` | 즐겨찾기. 브라우저에서만 |
| `formatShort(iso)` | `260920` |
| `formatFull(iso)` | `20260920` |

항목의 `id`는 `` `${Date.now()}-${Math.random().toString(36).slice(2, 7)}` ``로 만든 겹치지 않는 값이고, `serverNoteId`는 서버가 준 번호예요.

**참고:** 백엔드가 없으면 `serverNoteId`가 없어서 수정과 삭제가 안 돼요. 일부러 그렇게 만든 거예요.

`DEMO_QUOTES`: `?demo=1`일 때 보이는 예시예요.

### `QuoteModals.jsx`

- **`Frame`**: 어두운 배경과 가운데 팝업.
- **`AutoTextarea`**: 글에 따라 높이가 늘어나는 입력칸. `useLayoutEffect`에서 높이를 `auto`로 했다가 `scrollHeight`(글 전체 높이)로 맞춰요. `useLayoutEffect`는 화면에 보이기 **직전에** 실행돼서 깜빡임이 없어요.
- **`QuoteBody`**: 큰 따옴표가 있는 문장 영역.
- **`Actions`**: 취소/완료 버튼.
- **`QuoteDetailModal`**: 보기.
- **`QuoteEditModal`**: 수정. 내용이 바뀌어야 완료가 켜져요.
- **`QuoteAddModal`**: 추가. 책을 고르고 쪽수를 넣어요. 타이머에서도 이 팝업을 써요.

### `Quote.jsx`

**`sortQuotes(list, sort)`**: 최신순은 쓴 시각, 날짜순은 날짜가 오래된 순이에요. `[...list]`로 복사한 뒤 정렬해요. `sort`는 원본 배열을 바꾸거든요.

**`QuoteRow`**: 한 줄이에요. `•••` 버튼에 `e.stopPropagation()`을 써서 줄 클릭(보기)과 겹치지 않게 해요.

**`Quote`** state: `sort`, `menuId`(메뉴가 열린 줄), `detailId`(보기), `editId`(수정), `adding`(추가), `saving`.

| 함수 | 하는 일 |
|---|---|
| `guardDemo()` | 예시 화면이면 막고 알림 |
| `handleFavorite(quote)` | 즐겨찾기 |
| `handleDelete(quote)` | 확인 후 삭제 |
| `handleEdit(quote)` | 수정 팝업 열기 |
| `submitEdit(text)` | 수정 저장 |
| `submitAdd({ book, page, text })` | 추가 저장 |
